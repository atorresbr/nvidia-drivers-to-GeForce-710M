# nvidia-drivers-to-GeForce-710M to POP_Os Linux 
This bash script install nvidia drivers to GeForce 710M 
```
wget https://raw.githubusercontent.com/atorresbr/nvidia-drivers-to-GeForce-710M/refs/heads/main/geforce710m.sh &&
chmod +x geforce710m.sh && sudo install ./geforce710m.sh

```
